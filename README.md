# 📌 PureLeaf Dashboard Admin

**PureLeaf Dashboard Admin** is a modern React admin portal for managing digital menu systems.  
It provides a secure and intuitive interface for restaurant owners and managers to handle menus, analyze user interactions, manage teams, and configure settings—all in one place.

---

## 🚀 Features

### Authentication & Authorization
- 🔐 **Register:** Create new user accounts
- 🔑 **Login / Protected Routes:** Access control using `ProtectedRoute`
- 🔄 **Forget Password & Reset Password:** Recover accounts seamlessly

### Admin Dashboard
- 📊 **Dashboard Overview:** Quick insights with summary cards, charts, and analytics
- 🍽 **Menu Management:** Add, edit, and remove menu items dynamically
- 📈 **Analytics:** Track menu item popularity, QR interactions, and user engagement
- ⚙️ **Settings:**
  - **Profile:** Update user information
  - **Password:** Secure password updates
  - **Team:** Manage team members and roles

### UI & UX
- 🎨 Responsive design with Tailwind CSS
- 🖌 Reusable components for buttons, lists, modals, and forms
- 📦 State management using React Context & TanStack Query
- 🔔 Toast notifications using **Sonner** for user feedback

### Advanced Features
- 🖼 QR Code generation (with images and customization)
- 📁 Organized folder structure for scalability
- 🧪 Integration-ready with external APIs

---

## 🧰 Tech Stack

| Technology | Purpose |
|------------|---------|
| React 18+ | Frontend library for building UI |
| React Router DOM v6 | Client-side routing |
| TanStack Query | Data fetching, caching, and synchronization |
| Sonner | Toast notifications |
| Tailwind CSS | Styling and responsive design |
| Headless UI | Accessible UI components (like Listbox) |
| Axios (optional) | API requests |
| npm | Package management |
